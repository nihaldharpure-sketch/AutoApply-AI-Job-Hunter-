# AutoApply-AI-Job-Hunter-
🎯 Project Spotlight: AutoApply AI — Automated Job Application System
I recently built a full-featured, production-ready web application that automates the job application process end-to-end.
6 months ago I was applying to jobs manually — one by one — copy-pasting cover letters, losing track of where I applied, feeling burnt out.
So I built a tool to fix that. 🔧
Introducing AutoApply AI — my own automated job application system, built from scratch.
Here's how it works:
1️⃣ Upload your resume (PDF or DOCX)
2️⃣ It reads and parses your skills using AI
3️⃣ It fetches real job listings from LinkedIn, Indeed & Glassdoor
4️⃣ It scores each job based on how well your skills match
5️⃣ You click Auto Apply — it handles the rest
6️⃣ You get an email notification in your inbox after every apply ✉️
The whole thing runs in the browser. No backend. No login required. Your data never leaves your device.
What I built it with:
→ Vanilla HTML, CSS & JavaScript (no React, no Vue — pure frontend)
→ PDF.js for resume parsing
→ Chart.js for the analytics dashboard
→ RapidAPI for live job data
→ Web3Forms for email alerts
→ Netlify for deployment
It's not perfect. But it's real, it works, and I built every line of it myself.
